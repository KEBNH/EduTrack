# EduTrack

## Sistema de Alerta Temprana (SAT) para la Prevención de la Deserción Escolar en el Perú

EduTrack es una plataforma académica orientada a la detección temprana del riesgo de deserción escolar mediante el análisis automatizado de indicadores educativos como asistencia y rendimiento académico.

La plataforma busca transformar el modelo reactivo tradicional en un enfoque preventivo basado en datos, permitiendo a docentes, tutores y personal especializado intervenir de manera oportuna y eficiente.

## Objetivos

- Detectar patrones de riesgo escolar.
- Centralizar información académica.
- Generar alertas tempranas.
- Facilitar intervenciones educativas.
- Proteger la privacidad de los estudiantes.

## Funcionalidades

- Registro de asistencia.
- Monitoreo académico.
- Gestión de alertas.
- Seguimiento de intervenciones.
- Panel de control para personal autorizado.
- Análisis de riesgo automatizado.
